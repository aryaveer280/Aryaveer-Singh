Heart Rate Data Visualizer ❤️
A beginner-friendly Python project that reads heart-rate measurements from a CSV file, summarizes the data, and creates charts.
Important: The included dataset is fictional sample data created for learning and demonstration. It is not real patient data and must not be used for diagnosis or medical decisions.

Features
•⁠  ⁠Loads heart-rate data from a CSV file using Pandas.
•⁠  ⁠Calculates the number of readings, average, minimum, and maximum heart rate.
•⁠  ⁠Prints a summary grouped by activity.
•⁠  ⁠Saves a line chart of heart rate across the recorded observations.
•⁠  ⁠Saves a bar chart showing average heart rate for each activity.
•⁠  ⁠Checks for missing values and basic invalid readings.
Customize the project
•⁠  ⁠Add more dates and readings.
•⁠  ⁠Add a device column to compare devices (you would also update the code).
•⁠  ⁠Record additional activity categories.
•⁠  ⁠Add a moving-average line or compare days.
Limitations and responsible use
•⁠  ⁠The dataset is fictional and very small.
•⁠  ⁠Heart rate varies with age, fitness, health, medication, stress, and many other factors.
•⁠  ⁠Activity labels and sample values are illustrative only. This program does not determine whether a heart rate is medically normal or abnormal and is not a diagnostic tool.
•⁠  ⁠If you use real data, remove identifying details and ensure you have permission to use it.
